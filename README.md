# Pink Home

A clean pink home screen for Samsung TVs, run through [TizenBrew](https://github.com/reisxd/TizenBrew).
It shows the time, the Bristol weather, and six apps: Netflix, YouTube, Prime Video, BBC iPlayer, ITVX and Channel 4.

## Install
In TizenBrew on the TV: Module Manager → Add → GitHub module → `Kippsterrr/pink-launcher`.

## Remote
Left/right to move, OK to open, number keys 1–6 jump straight to an app, Back to exit.
